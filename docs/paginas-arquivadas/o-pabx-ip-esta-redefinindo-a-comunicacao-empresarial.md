## **O que é PABX IP?**

PABX IP significa **Private Automatic Branch Exchange Internet Protocol** (Troca Automática de Ramais Privados via Protocolo de Internet). Traduzindo: é um sistema telefônico que utiliza a internet para gerenciar chamadas e conectar ramais internos e externos.

Ao contrário dos sistemas PABX tradicionais que dependem de linhas fixas, o PABX IP funciona por meio de tecnologia VoIP (**Voice over Internet Protocol**). Isso significa que ele converte sua voz em dados digitais que são transmitidos pela internet. Legal, né?
